# Schnitzeljagd Rätselbaukasten

Eine kleine Web-App, mit der du schnell Rätsel für Kinder erstellen kannst – perfekt für Schatzsuchen, Geburtstagsfeiern oder den Unterricht.

## Features

- Themenauswahl mit Zufallsvorschlag
- Automatische Text- und Hinweisideen passend zum Thema
- Verwaltung von Hinweisen und Mini-Aufgaben
- Live-Vorschau mit Druck/PDF-Ausgabe
- Export per Kopieren in die Zwischenablage

## Nutzung

1. Öffne die Datei `index.html` im Browser.
2. Wähle ein Thema, Titel und beschreibe dein Rätsel.
3. Nutze die Buttons, um Vorschläge für Geschichte, Hinweise und Aufgaben zu erhalten.
4. Klicke auf **Rätsel zusammenstellen**, um die Vorschau zu aktualisieren.
5. Exportiere das fertige Rätsel als Text oder speichere es über den Druckdialog als PDF.

## Entwicklung

Es werden keine zusätzlichen Abhängigkeiten benötigt. Passe bei Bedarf die Dateien in `assets/` an, um weitere Themen, Hinweise oder Layouts zu ergänzen.
